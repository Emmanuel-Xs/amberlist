Empty state with an original illustration, a title, one line of help and an optional action. Use on every list that can be empty.

- Props: `illustration` tasks | done | notes | folder | habits | search | offline, `title`, `text`, `illustrationWidth`, children (buttons).
- Copy says what to do next: "No tasks here yet. Add one above or press Q."
- Illustrations are decorative (`aria-hidden`); the title carries the meaning.
- Available alone as `Illustration` for other places (onboarding, offline banner).
