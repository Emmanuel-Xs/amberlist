Line icon on a 24px grid, 1.75 stroke, round caps, drawn in currentColor. Names map one to one to lucide-react (see Iconography in the README).

- Props: `name`, `size` (16, 18, 20, 22, 24 up to 56), `strokeWidth`.
- Decorative by default (`aria-hidden`); the button around an icon-only control carries the `aria-label`.
