Square pastel tile for a category with its task count. Custom component (a shadcn `Card` restyled).

- Props: `title`, `count`, `tone` lavender | butter | mint | peach | sky, `icon`, `onClick`.
- Phones: a horizontal scroller showing about 2.3 tiles; `bp-sm` 3 across; `bp-lg` a 4 or 5 column grid.
- Text on tiles is always `on-pastel`, in both themes.
- Uses a large line icon in place of illustrations; swap in your own illustrations if you have them.
